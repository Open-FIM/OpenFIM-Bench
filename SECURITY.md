# Security & Data Privacy Policy

## Reporting a vulnerability

If you discover a security vulnerability in OpenFIM-Bench code or tooling,
please report it privately via GitHub's "Report a vulnerability" feature
under the repository's Security tab, rather than opening a public issue.
We'll acknowledge reports and aim to respond with a remediation plan
promptly.

## Reporting a data/privacy concern

Because this project works with health-related population data, please
also report — privately, the same way — any instance where you believe:

- Potentially re-identifiable or restricted-access data (e.g., MIMIC
  derivatives) has been committed to the repository
- A benchmark case or example inadvertently exposes real individual
  information rather than de-identified or synthetic data

We treat these reports with the same urgency as security vulnerabilities
and will remove affected content as quickly as possible.
